# 会話にTimelineを追加する手順

既存の `Dialogue Timeline Sequence Controller` に演出を登録し、会話CSVの `Animation` 列から開始・終了します。新しいスクリプトは不要です。

通常の猫Presentation状態は `Idle`（通常待機）、`Conversation`（会話中）、`Timeline`
（演技中）です。Timelineを再生する処理はPresentation Controllerが直前の通常状態を
保持し、完了・中断・スキップ時に自動復帰します。イベント側から単体Timelineを再生する
場合も、同じ `DialogueTimelineSequenceController.PlayTimeline` を利用してください。

## Animatorとの共存

Timeline再生中も通常Animatorは稼働させます。呼吸・瞬き・待機姿勢などはAnimator側を
継続し、Timelineは演技に必要な部位だけを上書きします。各Animation Trackには、演技対象の
ボーンだけを含むAvatar Maskを設定してください。たとえば左前脚の演技では、胴体や頭を含めず
左前脚の付け根から先だけをMaskへ含めます。

視線や別の演出と本当に競合する場合だけ、Sequenceの `Additional Behaviours To Suspend` に
対象Behaviourを登録します。通常のAnimator、Cat Presentation Controller、Cat Animation Runtimeを
この欄へ登録して待機全体を止めないでください。

### Animation TrackからAvatar Maskを生成する

Timeline上の `Animation Track` を選択し、Inspectorの右クリックメニューから
`Auto Generate Avatar Mask` を実行します。`Tools > Nekolpos > Timeline > Auto Generate Avatar Mask for Selected Track`
からも実行できます。ツールは有限ClipとInfinite ClipのTransform位置・回転・スケールCurveを
和集合として解析し、Curve対象とAnimatorルートまでの親だけをTransform Maskへ登録します。
親は階層を成立させるための登録のみで、実際に有効化するのはCurve対象Transformだけです。

生成先は `Assets/Animation/AvatarMasks/AutoGenerated/` です。同じTimeline・Track名のMaskがある場合は、
更新、既存Maskを再適用、キャンセルを選べます。TrackへのMask設定と `Apply Avatar Mask` の有効化はUndo可能です。
対象モデルを特定できない場合は変更せずWarningを出します。通常は選択中TrackのTimelineを再生する
PlayableDirectorのBinding、選択中Animator、Cat Presentation Controllerの通常Animator、唯一一致するAnimatorの順で解決します。
複数の候補しかない場合は、対象Animatorも選択してから実行してください。

## 1. Timelineを用意する

演出ごとに、開始用・繰り返し用・終了用の3本を用意します。現在の `Maw` は `MawStart` / `MawLoop` / `MawEnd` です。3本とも長さが0秒より大きいTimelineを指定してください。

- 対応するのは猫用の `Animation Track` です。カメラ・Audio・Signalなどのトラックは、この会話シーケンスでは扱いません。
- 各トラックは実行時に `Normal_Cat` のAnimatorへ接続されます。録画するボーンの相対パスも `Normal_Cat` を基準にしてください。
- 待機用の `CatSimple_Lie_belly_loop_1` をTimelineへ入れることは必須ではありません。通常待機はAnimator Controller側に残します。全身の姿勢を演出する場合は、その姿勢に必要なアニメーションをTimelineで明示してください。
- 同じボーンを複数トラックで動かす場合は、上書き・混合によって意図した動きが弱くならないか確認してください。

## 2. シーンに登録し、視線を設定する

Playを停止し、`TitleScene > OpenBetaSystems` を選択します。Inspectorの `Dialogue Timeline Sequence Controller > Sequences` に要素を追加し、次を設定してシーンを保存します。

| 項目 | 設定例・意味 |
| --- | --- |
| Id | `Maw`。演出を識別する重複しない名前 |
| Start | 開始用の `MawStart` Timeline |
| Loop | 繰り返し用の `MawLoop` Timeline |
| End | 終了用の `MawEnd` Timeline |
| Keep Look At During Timeline | オンで演出中も既存の視線制御を継続。オフ（初期値）では視線の影響だけをフェードアウトし、終了後にフェードイン |
| Phase Transition Seconds | Start→Loop、Loop→End、End→待機の姿勢と、視線OFF時のウェイトを補間する時間。初期値は `0.12` 秒。`0` で即時切替 |

視線のオン・オフは演出ごとに決めます。オフでも視線コンポーネントと注視対象は保持され、影響度だけが `1 → 0 → 1` と補間されます。オンの場合、視線システムが制御する目・頭をTimelineでも同時にキー指定すると動きが競合するため、担当する部位を分けてください。

Timelineを編集する時は、`NekomataLookRigController` の `Apply Editor Preview During Timeline` をオフ（初期値）のままにしてください。この状態ではEditor視線Rigを退避し、Timelineだけが首・頭・目を制御するため、キー編集結果を後から上書きしません。Play相当の視線を重ねた構図を確認したい時だけ、この項目をオンにします。オンの場合は、シーンに登録された同じSequenceの `Keep Look At During Timeline` を参照します。`MawStart` / `MawLoop` / `MawEnd` のようにオフで登録したTimelineでは、Timeline開始直前の頭・目の向きを保持して表示します。オンの場合はプレビュー中も注視対象を追従します。

`Normal_Cat` のEditor Previewは、Runtimeと同じ `RigBuilder` / `MultiAimConstraint` と `PlayerLookTarget` のオフセットを使います。Sceneに保存された視線Rigが見つからない場合だけ、従来の直接ボーン回転へフォールバックします。

Startの終端とLoopの先頭、LoopとEndの先頭には、同じ姿勢のキーを置くと最も自然です。Loopを繰り返す場合は、先頭と末尾も同じ姿勢にします。`Phase Transition Seconds` はアセット間・Loop周回時にわずかな差が残る場合の補正であり、大きく異なる姿勢を隠す用途にはしません。注視元が変わらない場合、視線をオンにしても同じ対象を維持したまま首・頭のTimeline姿勢だけを補間します。

## 3. 会話の行に開始・終了を指定する

会話プレビュー・編集ツールで対象の会話・Pattern・行を選び、`Animation` に入力します。

| 実行したい操作 | `Maw` の入力例 |
| --- | --- |
| この行の表示開始時に演出を開始 | `timeline_sequence:MawStart` |
| この行の表示開始時に演出を終了 | `timeline_sequence:MawEnd` |

命令の `Maw` は、手順2で登録した `Id` に対応します。別の演出なら、そのIdに `Start` / `End` を付けます。Timelineアセットのファイル名だけを入力しても実行されません。

開始するとStartを1回再生し、Loopへ自動移行します。LoopはEnd命令まで続くため、終了行も指定してください。次の行への移動や会話の終了だけでは止まりません。End命令はStartの途中でも実行されます。End Timelineの完了は会話行を自動で送らないため、最終行はプレイヤーの次へ操作まで表示されます。

現在のID `00450`（「かんで」）では、Pattern `1` のOrder `3` が開始、Order `4` が終了です。Order `3` で少し待ってLoopを確認し、Order `4` へ進めて終了を確認します。会話の1行目から始まる設定ではありません。

## 4. ゲーム用データへ反映して確認する

1. 会話プレビュー・編集ツールでCSVを保存する。
2. Unityメニューの `Nekolpos > CSVを暗号化バイナリへ変換` を実行し、Consoleで成功を確認する。
3. Playを再開始し、対象の会話を実行する。

ゲームは `Assets/Resources/TalkData` の暗号化データを読み込みます。CSVを保存しただけではゲーム用データに反映されません。

「かんで」は `SpeechControl=Sequence` のため、同じPlay中に再入力すると次のPatternへ進みます。Timeline命令は現在Pattern `1` だけにあるので、繰り返し確認する場合はPlayを再開始してください。

再生しない場合は、実際に表示しているPattern・行、登録したId、3本のTimeline、暗号化の成功を確認します。Consoleの `[DialogueTimelineSequence]` または `[DialogueManager]` のエラーも確認してください。
