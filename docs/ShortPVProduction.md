# ネコルポスのショートPV制作手順

## 指示をショット表にする

着手時に、最新の指示を「ショット」「映像の出典」「使う区間」「発話と字幕」「切り替え点」に分けて記録する。指定された原稿、使用素材、保存先を優先する。元Timeline、元録画、完成動画の秒数は別々に記録し、カット前の時刻指定を完成動画の時刻に読み替えない。

- 実プレイ指定の箇所は、指定された録画の場面を使う。たとえば「なでなで」と「そんな会話ができる……」だけが実プレイ指定なら、その2箇所だけに使い、残りは専用撮影する。
- 「カメラに向かってジャンプ」「『高評価もしてね』と話しかける」など、秒数と動作の両方で元録画を照合する。誤変換の途中、不要な選択肢、開発UI、意図しない別シーンが入る前後は切る。
- 対局や試遊の画面は実プレイの結果を使う。勝敗、点数、接触結果を演出で作り替えない。
- 原稿は支給された文を使う。字幕の表記と読み上げの読みは別々に扱う。たとえば字幕が「取り憑いて」、読み上げが「とりついて」と指定された場合は両方を個別に確認する。

## 撮影時に見ること

- 専用撮影は撮影用Sceneや隔離環境で行う。開いている本編Sceneに未保存変更がある場合、必要な座標は読み取りで控える。Playや録画を始める前に、承認範囲と保存データの分離を確認する。
- ゲームの実物の部屋、ちゃぶ台、ベッド、トイレなどを使う。部屋と卓の材質や輪郭が分かれ、人物の足元が床や寝具に乗っているかを画面で見る。同じ背景が続く場合は、内容に合わせて撮影場所や画角を変える。
- 5cmの人物は、ネルコの前足や顔との比率が伝わる位置へ置く。カメラへ近づけすぎると巨大猫との体格差が弱まる。対面指定ではネルコの身体の正面に置き、人物の体と視線を相手に向ける。構図の判断が必要なら、同じレンズで位置だけ変えた候補を並べる。
- なでるカットは、指先が額や鼻の指定位置に届き、指が埋もれず、脇・肘・手首が自然に見える角度で撮る。接触中に加え、手を上げる途中と離す途中も確認する。人物の胴体や袖を貫通していないかも見る。
- 背中に乗るカットは肩寄りの位置、前屈姿勢、座面と手の接触を確認する。歩行中に人物が背中と一緒に上下し、隙間や貫通が目立つフレームを避ける。指定ルートがあれば部屋のランドマークで始点と終点を確認する。
- 二股の尻尾などが説明の主題なら、全身で場所が分かるカットと、両端を同時に見分けられる寄りのカットを用意する。家具で隠れる、耳や顔が文字で塞がる、カメラを寄せると目的の部位が切れる場合は、位置と画角を再調整する。

## ナレーションと字幕を合わせる

- ネルコの会話は指定のウィンドウに表示する。別途指定がある場合だけ声を付ける。ずんだもんが会話に重ねて喋る指定では、ネルコのウィンドウを表示したまま、双方の文字が読める位置にナレーション字幕を置く。
- 字幕は発話区間ごとに出して消す。冒頭、改行、助詞、句読点、文字化け、画面端の見切れを完成画像で確認する。読み上げの途中では画を切らず、発話が終わるまで前の場面を残す指定を守る。
- 驚きの返しは相手が話し始めるタイミングに合わせる。「えっ！？君喋るの！？」のような割り込みは、先に驚かず、意図した間で重ねる。指定の話者の発話が確認できるところから次へつなぐ。
- 画に対応しない風切り音や繰り返しのSEを外す。着地など動作に合った音は画と合わせる。音量と字幕を確認し、原稿にない間延びやほぼ静止した尺を詰める。
- 指定された既定エンドカードのロゴ、背景、配置、CTAを使う。「ネコルポスはSteamで……」などカード上で読む指定の音声は、カード表示に合わせる。自由会話の応答方式についての文言を、ゲーム全体や制作工程の説明へ広げない。

## サムネイルと納品の確認

- 縦サムネイルは1080×1920を基本に、上部の指定見出しを大きく読みやすくし、下部に共通の日本語横長ロゴを置く。絵文字、色変更、強調する語、入力欄の文言は個別指示に合わせる。
- 画像は、指定の秒数と動作を照合して選ぶ。「別アングル」は同じポーズを撮影用カメラで撮り直す。接触、表情、二股の先端、人物との体格差など、そのサムネイルで伝えるものを中央に置く。文字で隠れる場合は被写体とカメラの位置から調整する。
- 縮小表示で見出し、顔、手、ロゴが一目で読めるか確認する。複数案を求められたら、ラベル付き比較画像とフルサイズの個別PNGを用意する。
- 字幕あり／なしは同じ映像の編集点と同じ音声を使い、指定のナレーション字幕だけを切り替える。ネルコの会話UI、エンドカード、必要な音声クレジットは指示に沿って両版に残す。VOICEVOX使用時は使用した音源のクレジットを確認する。
- 完成ファイルの冒頭、各カット前後、最後を実際に確認する。両版のフレーム数、解像度、音声一致、全編デコード、指定フォルダへの保存を確認する。前の完成版を差し替える場合は退避を作り、納品リンクは保存先の実ファイルを指す。
