# 2026-09-11 操作性・安定性改善

## 対象

`TitleScene` のタイトル・会話・ポーズメニュー・会話履歴を確認し、PCとスマートフォンで共通して使いやすくなる表示・タップ操作・安定性を改善した。会話本文の自動生成や、新規のキーボード操作は追加していない。

## 実装

- ポーズメニューに背景の遮蔽、64pxのメニューボタン、閉じるボタン、背景タップで閉じる操作を追加した。
- ポーズ中は会話送り、選択肢、外部IME送信を止め、入力済みの下書きと元の入力可否を閉じた後に復元する。
- ポーズ解除時には、開く前の `Time.timeScale` をそのまま戻す。無効化・シーン切替中の解除も同じ経路にする。
- BGM/SEの保存済みミュート設定を、実行中に追加された `AudioSource` にも再生前に反映する。
- 通常テーマのボタンは二重に色を掛けないようにし、淡色ボタン上の文字を濃色へ変更して可読性を確保した。不穏テーマの明色文字は維持する。
- 履歴は `LogId` ごとに行を再利用し、追加・更新・削除があった行だけを作り直す。最新を読んでいるときだけ追従し、途中まで戻っているときは位置を維持する。
- 履歴本文を22pxへ拡大し、本文の長さに合わせて行高を取る。選択チェックは56pxのタップ領域にした。
- 会話CSVの応答セルにある引用符付き改行を段落として保持する。`|`区切りの別候補とJSON配列の扱いはそのままにした。
- `KanjiReadingDictionary` のEditor専用キャッシュをプレイヤーへ含めず、WebGLの未使用フィールド警告を解消した。
